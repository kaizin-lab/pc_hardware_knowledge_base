# Оперативная память (RAM)

Актуальный стандарт — DDR5 (AM5 и LGA1851). DDR4 — уходящий стандарт LGA1700, новые entry не заводятся.

## Sweet spot для AM5

- **6000 MT/s CL30** — 1:1 с Infinity Fabric (UCLK=MCLK), лучшая производительность
- **5600 MT/s CL36** — бюджетный вариант, теряет ~3-5% FPS

## Как выбирать

1. **Гейминг / общая сборка** → DDR5-6000 CL30 (sweet spot)
2. **Бюджет** → DDR5-5600 CL36
3. **Специфичный разгон / максимальный FPS** → DDR5-6400 CL32 (требует ручного тюнинга UCLK на AM5)
4. **Сервер / рабочая станция (стабильность 24/7)** → DDR5-5200 CL40 JEDEC (нулевой риск ошибок)
