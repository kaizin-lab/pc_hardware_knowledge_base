# AM5 (LGA1718) — материнские платы

Сокет AM5 для процессоров AMD Ryzen 7000 (Zen 4) и Ryzen 9000 (Zen 5).

## Чипсеты AM5

| Чипсет | PCIe 5.0 GPU | PCIe 5.0 M.2 | USB 3.2 Gen2x2 | Позиционирование |
|---|---|---|---|---|
| **B650** | Нет (4.0) | Да (1 порт) | Опционально | Средний сегмент |
| **B650E** | Да | Да | Опционально | Средний + PCIe 5.0 |
| **X670** | Нет | Да | Да | Энтузиасты (dual chipset) |
| **X670E** | Да | Да | Да | Флагман |
| **B850** | Нет | Да (Gen5) | Да | Обновлённый средний |
| **X870** | Да | Да | Да | Обновлённый флагман |

### Что ещё нужно заполнить

- B650E: ASRock Riptide, ASUS Strix
- B850: обновлённые средние платы (Wi-Fi 7, USB4 опционально)
- X870: флагманские платы под Zen 5
- LGA1851: платы под Intel Arrow Lake (Z890, B860) — **новая папка**

## Что смотреть при выборе AM5-платы

1. **VRM-фазы и сила тока** — достаточно ли для целевого CPU (см. `../../../concepts/vrm-phases.md`)
2. **PCIe-конфликты** — какие слоты отключаются при использовании M.2 (см. `../../../concepts/pcie-lanes.md`)
3. **Flashback без CPU** — критично для обновления BIOS под новые поколения
4. **Сетевой контроллер** — Intel i225/i226 vs Realtek (стабильность под Windows)
