# LGA1700 — материнские платы

Сокет LGA1700 для Intel 12-го (Alder Lake), 13-го (Raptor Lake) и 14-го (Raptor Lake Refresh) поколений.

## Чипсеты

| Чипсет | Разгон CPU | PCIe 5.0 | DDR4/DDR5 | Позиционирование |
|---|---|---|---|---|
| B660 | Нет | Нет | Оба (зависит от платы) | Бюджет/средний |
| Z690 | Да | Да | Оба | Энтузиасты |
| B760 | Нет | Нет | Оба | Средний |
| Z790 | Да | Да | Оба | Флагман |

> LGA1700 — **тупиковый сокет**. Intel Core Ultra (Arrow Lake) использует LGA1851.
