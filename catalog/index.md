# Каталог компонентов

Это корень каталога. Здесь лежат все компоненты ПК-железа, организованные по типу.

## Структура

| Директория | Тип | Файлов | Описание |
|---|---|---|---|
| `cpu/` | процессоры | ~4 | AMD Ryzen, Intel Core — поколения и архитектуры |
| `gpu/` | видеокарты | ~4 | NVIDIA GeForce, AMD Radeon, Intel Arc |
| `motherboard/` | мат. платы | ~6+ | По сокетам: am5/, lga1700/ |
| `memory/` | оперативная память | ~2 | DDR4, DDR5 |
| `storage/` | накопители | ~3 | NVMe (pcie-gen4, gen5), SATA SSD |
| `psu/` | блоки питания | ~2 | ATX 3.x, SFX |
| `cooling/` | охлаждение | ~3 | Воздушное (air/), жидкостное (liquid/) |
| `case/` | корпуса | ~2 | Форм-факторы |
| `monitor/` | мониторы | ~2 | Игровые 4K, профессиональные |

## Как искать

1. Загрузи `index.md` нужной поддиректории — он покажет таксономию и связи внутри группы
2. Или используй `scripts/query.py` для выборок по атрибутам (vendor, socket, tags)

## Сквозные концепты

Концепты, не привязанные к одному типу компонентов, лежат в `../concepts/`:
- `vrm-phases.md` — фазы питания, удвоители, real vs advertised
- `pcie-lanes.md` — линии PCIe, конфликты, sharing groups
- `memory-timings.md` — тайминги, ранги, MCLK:UCLK
- `power-budget.md` — бюджет мощности, пики потребления, ATX-спецификации
