## Параметры выбора

- **Форм-фактор MB** — ATX, MicroATX, Mini-ITX
- **Клиренс кулера** — высота (мм) для воздушного охлаждения
- **Поддержка радиаторов** — сверху / спереди, размеры
- **Макс. длина GPU** — критично для RTX 4090 (340+ мм)
- **Airflow** — mesh-перед, количество и размер вентиляторов
